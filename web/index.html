        Your client

          Connect this moon

          Run these on any device to join the network and use this moon as a root anchor.

          zerotier-cli join <network-id>
          zerotier-cli orbit <moon-id> <moon-id>
          curl -fsSL https://raw.githubusercontent.com/Crashcart/zerotierone-moon/dev/get-latest-dev.sh | sudo bash

          Linux / macOS

          1. Install ZeroTier: curl -s https://install.zerotier.com | sudo bash
          2. Join the network: zerotier-cli join <network-id>
          3. Orbit the moon (command above).
          4. Verify: zerotier-cli listpeers | grep <moon-id>

          Windows

          1. Install the ZeroTier One MSI from zerotier.com.
          2. Join the network from the tray app.
          3. Drop the .moon file into C:\ProgramData\ZeroTier\One\moons.d\.
          4. Restart the ZeroTier One service.
